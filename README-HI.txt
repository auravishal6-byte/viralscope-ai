VIRALSCOPE AI - STARTER PROJECT

1) Google Cloud Console par project banao.
2) YouTube Data API v3 enable karo aur API key banao.
3) Is folder mein .env.example ko copy karke .env naam do.
4) .env mein YOUTUBE_API_KEY=YOUR_KEY set karo.
5) Terminal mein:
   npm install
   npm start
6) Browser mein http://localhost:3000 kholo.

CAPACITOR:
- Is project ko apne Capacitor app ke web project mein merge kar sakte ho.
- Capacitor config mein webDir "public" rakho.
- API backend ko publicly deploy karna hoga; Android APK mein localhost API key expose mat karo.
- Server URL ko frontend ke fetch('/api/video...') ke liye production API base URL se configure karna hoga, ya same-origin proxy set karna hoga.
- API key ko APK / frontend JavaScript mein kabhi mat daalo.

IMPORTANT:
- Public YouTube API statistics as-is display hote hain.
- Performance comparison creator ke manually entered YouTube Studio numbers par hota hai.
- App YouTube recommendation algorithm ko nahi jaanta aur viral hone ki guarantee nahi deta.
- YouTube API developer policies, YouTube Terms aur privacy requirements follow karo.
